# React To-Do List App

A React-based To-Do List application built with Tailwind CSS and React Router.  
Includes authentication flow (Login & Signup), dynamic routing, and modular component structure.

## Features

- React functional components
- Tailwind CSS styling
- React Router (BrowserRouter, Routes, Link)
- Login and Signup pages
- useLocation & useNavigation usage
- Temperature, City, and Date info cards
- Functional To-Do list (Add tasks)
- Component-based architecture

## Tech Stack

- React
- React Router DOM
- Tailwind CSS
- JavaScript (ES6+)

## Project Structure

- Header section with info cards
- Authentication pages (Login / Signup)
- To-Do list with input and add functionality
- Modular components for maintainability
